# Dibyajyoti Mohanty Portfolio

Personal portfolio website for Dibyajyoti Mohanty, a Java Full Stack Developer focused on Java, Spring Boot, ReactJS, Oracle SQL, AWS, and DevSecOps-ready project workflows.

## Features

- Responsive React portfolio built with Vite
- Bootstrap and Bootstrap Icons UI styling
- Light and dark theme selector in the navbar
- Animated portfolio loader
- Project cards with GitHub links
- Training, skills, contact, and resume sections
- Downloadable resume from the public assets folder

## Tech Stack

- React 18
- Vite
- Bootstrap 5
- Bootstrap Icons
- GSAP
- CSS3

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Deployment

This project is ready for Vercel.

- Build command: `npm run build`
- Output directory: `dist`
- Framework preset: Vite
